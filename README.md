# Dilafruz — premium mehr sahifasi

## Ishga tushirish
1. `Dilafruz_premium` papkasini Visual Studio Code'da oching.
2. `index.html` faylini brauzerda oching. Qulayroq ishlash uchun VS Code'da Live Server kengaytmasidan foydalaning.
3. Internetdagi Google Fonts yuklanmasa ham sahifa ishlaydi; faqat shrift zaxira shriftga almashadi.

## Fayllar
- `index.html` — sahifa tuzilishi
- `style.css` — moslashuvchan dizayn va yengil animatsiyalar
- `script.js` — bo‘limlar, 320 tadan ko‘p gap, keyingi gap, nusxalash va sevimlilar

## Muhim
Har bo‘limdagi gaplar brauzerda JavaScript orqali shakllantiriladi. Ayrim satrlarda takroriy ohang yoki avtomatik tuzilgan ibora sezilsa, `script.js` ichidagi `starters`, `endings` va `extras` ro‘yxatlarini o‘zing xohlagan Xorazmcha iboralar bilan almashtir. Sevimlilar shu qurilmadagi brauzer xotirasida saqlanadi.
